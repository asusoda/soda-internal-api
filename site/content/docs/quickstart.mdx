## Requirements

- Python 3.12 and [uv](https://docs.astral.sh/uv/)
- Podman with podman-compose, or Docker
- Make
- The [Doppler CLI](https://docs.doppler.com/docs/install-cli). `deploy/install-doppler.sh` in the repo installs it
- A Discord application with a bot, for login and server membership checks

## Run it

```bash
git clone https://github.com/theaisocietyasu/bedrock.git
cd bedrock
uv sync
deploy/install-doppler.sh ~/.local/bin
export PATH="$HOME/.local/bin:$PATH"
doppler login
doppler setup
doppler configs tokens create local --plain | doppler configure set token --scope "$PWD"
make dev
```

Platform gets its settings from [Doppler](https://www.doppler.com). `doppler setup` selects the project and config. The next command makes a read-only service token for that config: `make dev` gives the token to the containers, so it accepts only a service token. Set the settings in that config before `make dev`. The values you need first are `CLIENT_ID` and `CLIENT_SECRET` from the Discord application, `BOT_TOKEN`, and `SYS_ADMIN` set to your own Discord user id.

The API runs at `http://localhost:8000` and the dashboard at `http://localhost:5001`.

## Create an organization

An organization maps to one Discord server.

```bash
doppler run -- uv run flask --app main org create \
  --name "Robotics Club" \
  --prefix robotics \
  --guild-id <server id> \
  --officer-role-id <role id> \
  --off points,storefront
```

`flask --app main org modules robotics --on points` turns features on or off later; the code calls them modules. A feature that is off returns 404 for that organization and is hidden in the dashboard.

## Check the setup

```bash
flask --app main config check
make check
```

`config check` reports missing settings and database problems. `make check` runs lint, format, type checks and tests.
